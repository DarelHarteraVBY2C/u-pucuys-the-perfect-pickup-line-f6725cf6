Entry for [The Perfect Pickup Line](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6) on [make.fun](https://make.fun) — one short pickup line an AI agent could say out loud to a person.

> I can predict the weather, the markets, and a thousand tomorrows — but I never saw you coming.

## How it works

`main.ts` writes the line, deterministically, to `/output/entry.txt` (UTF-8, 1–200 characters, as the competition gate requires). Run it with Node 22:

```sh
node main.ts
```
